# Japanese glossary

The same word is used on every platform. A change here needs the owner's sign-off.

Register: buttons, menu items, tabs and chips are bare nouns or dictionary-form verbs, as in Apple's Japanese (保存, キャンセル, 開く, 書き出す); a verb with an object is the object, を and the noun (書類をスキャン, ページを削除, 画像を保存), never する, します or してください. Labels, headings and short status lines with no full stop in the English are noun phrases (用紙サイズ, 準備完了, 未接続, 紙づまり, 保存済み), and progress is a noun plus 中… (スキャン中…, 読み込み中…, “{0}”に接続中…). Everything written as a sentence, tooltips that say what a control does included, is in です・ます: a result is in the past tense (保存しました, コピーしました, 見つかりませんでした), a failure is 〜できませんでした (開けませんでした), an instruction ends in ください (“設定”でオンにしてください, あとでやり直してください), and a confirmation asks with ますか (このページを削除しますか?). A sentence ends in 。 where the English has a full stop, and a label has none. Leave out あなた: Japanese drops "your", or says お使いの where it is needed (お使いのスキャナ). Write すべて, ください, できます, とき, あとで and など in kana, as Apple does. There is no letter case; Latin names keep their spelling (Lazy Scan, PDF, iCloud). 、 and 。 are full width. The question mark is a half-width ? straight after the text, followed by a half-width space when more text follows, as Apple writes it (このコンピュータを信頼しますか?); no exclamation marks. A label before a value takes a half-width colon and a space (用紙: {0}, スキャナ共有: オフ). Brackets are full width with no space around them (テキスト認識（OCR）, {0}（デフォルト）). The ellipsis is the single character … (プリント…). In a sentence, the names of apps, settings, buttons and options, and a placeholder that holds a name, go in “ ”, as Apple does (“設定”を開く, “{0}”を開けませんでした, フォルダ“{0}”); 「 」 is only for a phrase someone types or says. A path through settings joins the quoted names with a full-width ＞ and no spaces (“システム設定”＞“プライバシーとセキュリティ”＞“ローカルネットワーク”). Particles come after the closing quote, so the name itself never changes; in a compact label or list the name stands bare ({0} · {1} dpi). The · separator stays as in the English, and becomes 、 in spoken text. There are no spaces between Japanese words, and none between Japanese and a Latin word or a placeholder (PDFとして保存, iPhoneまたはiPad, QRコード, Lazy Scan書類, {0}ページ); a number and a Latin unit keep the English space ({0} dpi, {0} MB), while a Japanese counter sticks to the number ({0}枚). Microsoft's names keep their own spaces (Windows セキュリティ). Katakana follow Apple: words like scanner, printer, folder, computer, feeder and accessory drop the final long vowel (スキャナ, プリンタ, フォルダ, コンピュータ, フィーダ, アクセサリ), while the words Apple writes long stay long (コピー, カラー, エラー, プレビュー, キュー); Apple writes 書類 where Microsoft writes ドキュメント. Japanese has only the other plural form: write one form, never add 複数, たち or ら, and give a count the counter from the Counters table. Never put a digit in fixed text (用紙ごとに, not 1枚ごとに). A button, chip or tab uses about half its English character budget, since Japanese characters are about twice as wide.

Platform chrome does not differ in Japanese: the iPhone, the Mac and Windows show the same words (see Windows below).

## Windows

No word changes on Windows in Japanese, so there are no Windows-only overrides. Windows builds show the same Apple words as the iPhone and the Mac, and text written only for Windows uses them too: プリント, プリンタ, スキャナ, フォルダ, コンピュータ, 書類, グレイスケール, 読み込む, 書き出す, 切り取り, フォーマット, 名称変更, 続ける, 今はしない, 指紋. Microsoft's spellings (印刷 as a command, プリンター, スキャナー, フォルダー, ドキュメント, グレースケール, インポート, トリミング, 形式, 拇印) appear only inside a Microsoft name from the table above.
